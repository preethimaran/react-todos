# React Todos
A minimalistic application that allows users to add tasks to their virtual todo list. [Click here](https://react-todos-gilt-delta.vercel.app/) to go to the website.

## Description
React Todos is a simple application built using React that enables users to keep track of all their Todo tasks in one place. Users can add tasks, mark them as completed/not-completed or remove them.

## Overview of React Todos functionality
- Add a task.
- Keep track of the completion status with checkboxes.
- Remove a task.
- Memory Persistance provided with local storage.

## Deployment
React todos has been deployed using Vercel. [Click here](https://react-todos-gilt-delta.vercel.app/) to access the website.

## Getting Started
### Installtion
Clone the Repo
```bash
git clone https://github.com/preethimaran/react-todos.git
```
Traverse to the project directory
```bash
cd react-todos
```
Install the dependencis
```bash
npm -i
```
### Running the project

Run the below in the project directory
```bash
npm run dev
```
Then open the below link in browser
```
localhost:5173
```
